Як будується розклад: цілочисельна модель CP-SAT

Розклад — це розв'язок задачі дискретної оптимізації: обрати для кожного рядка навантаження дні й пари в чисельнику та знаменнику так, щоб жорсткі правила виконувались завжди, а сумарний штраф за м'які правила був мінімальним.

§2Змінні рішення

xl,w,d,p ∈ {0, 1}1 — заняття l стоїть у тижні w, день d, пара p;  p ∈ Pg(l)
xl,0,d,p ≡ xl,1,d,pякщо lol = hil: заняття з цілим навантаженням однакові в обох тижнях (одна змінна)
yg,w,d,p = Σl ∈ Lg xl,w,d,pзайнятість групи (вираз, не окрема змінна)

Дробові заняття мають окремі змінні для чисельника і знаменника — саме вони й створюють різницю між тижнями.

§3Жорсткі обмеження

Будь-який знайдений розклад задовольняє їх без винятків.

H1yg,w,d,p ≤ 1у групи одне заняття в пару
H2Σl : t ∈ T(l) xl,w,d,p ≤ 1викладач не веде двох занять одночасно
H3Σl : t ∈ T(l) Σp xl,w,d,p ≤ 4у викладача не більше 4 пар на день
H4lol ≤ Σd,p xl,w,d,p ≤ hil,   Σw,d,p xl,w,d,p = nlнавантаження точно за планом, дробове — чергується
H5Σp yg,w,d,p ≤ 4у групи не більше 4 пар на день
H6Σl ∈ Lg,σ Σp xl,w,d,p ≤ 1без двох однакових дисциплін у день (якщо пар дисципліни ≤ 5)
H7Σl : cat(l) ≠ gym |T(l)| · xl,w,d,p ≤ Cзанять не більше, ніж аудиторій (C = 32, спортзал спільний)

У H4 рівність суми за два тижні разом з межами одного тижня і дає чергування: дисципліна з 1,5 пари має в одному тижні 1 пару, в іншому 2. Котрий тиждень отримує 2, розв'язувач обирає окремо для кожної дисципліни. Так дві «половинки» ділять одну пару, як у шаблоні коледжу:

§4М'які обмеження і штрафи

Кожне правило, яке в окремих випадках можна порушити, стає невід'ємною допоміжною змінною зі своєю вагою. Ваги відтворюють порядок пріоритетів з аркуша «Властивості розкладу».

День групи

Ng,w,d = Σp yg,w,d,p,   ag,w,d ∈ {0,1},   a ≤ N ≤ 4aa = 1 — день навчальний
ug,w,d ≥ 3ag,w,d − Ng,w,dнестача до 3 пар
bp ≥ yp − yp−1,   Σp bp ≤ 1 + γg,w,db — початок блоку пар; більше одного блоку = «вікно»

Bp ≥ zp,  Bp ≥ Bp−1;   Ap ≥ zp,  Ap ≥ Ap+1

§5Цільова функція: два етапи

Штрафи розділено на правила груп Fcore (етап 1 у таблиці) і якість для викладачів Fquality (етап 2). Задача розв'язується лексикографічно:

E1F*core = min Fcore(x)40% часу; зазвичай досягає 0 за 15–20 с
E2min Fcore(x) + Fquality(x)   при  Fcore(x) ≤ F*coreрешта часу; старт — з повного розв'язку E1

Обмеження в E2 гарантує, що покращення для викладачів ніколи не погіршить правила груп. Усі змінні етапу 2 отримують підказку (hint) значеннями з етапу 1, тому пошук починається з уже допустимого розкладу. Якщо другий етап не встигає, лишається розв'язок першого.

Розв'язувач — CP-SAT з Google OR-Tools: паралельний пошук на всіх ядрах (LNS, лінійні релаксації, пропагація обмежень).

§6Аудиторії

Аудиторії призначаються після розкладу окремим алгоритмом. H7 гарантує, що місць вистачає в кожну пару. Тип аудиторії визначається за назвою дисципліни, а кожен тип має рівні пріоритету з вартістю:

Дисципліна0 — бажано2060200
Фізична культураспортзал (спільний)———
Захист Українитирн.м, звичайні——
Комп'ютернікомп'ютерні класи (КН, ІПЗ — також 8, 9)звичайнірезервнілабораторія, бібліотека
Рештазвичайні—резервнілабораторія, бібліотека
  1. «Свій кабінет». Викладачі від найзавантаженіших. Для викладача обирається аудиторія найнижчої вартості, вільна в найбільшій кількості його пар; вона призначається на всі ці пари, решту пар обробляє наступна ітерація.
  2. Ремонт. Якщо заняттю не дісталося аудиторії, одне інше заняття в цей час переноситься в альтернативну вільну аудиторію.

Однакове заняття в чисельнику і знаменнику отримує одну аудиторію; підгрупи — різні. На даних коледжу виходить у середньому 1,8 аудиторії на викладача.

§7Календар: тижні й суботи

Модель будує тиждень пн–пт двічі (чисельник і знаменник). Реальна дата τ відображається на день розкладу так:

w(τ) = (⌊(τ − Mon(τ0)) / 7⌋ + w0) mod 2τ0 — початок семестру, w0 — його тиждень (зазвичай чисельник)
d(Satk) = k mod 5k-та субота семестру (k = 0, 1, …): пн, вт, ср, чт, пт, пн, …
Перевірка на файлах коледжу
Семестр з 01.09.2026: 23.09 — середа, знаменник; 26.09 — четверта субота (k = 3) → четвер, знаменник; 28.09 — понеділок, чисельник. Усе збігається з файлами «Розклад на …» з папки info/.
